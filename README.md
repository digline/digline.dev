# digline.dev

The one static page behind <https://digline.dev> — no framework, no build, no external request: system fonts, images in this repo, CSS inline in `index.html`.

GitHub Pages serves it from the root of `main`: `CNAME` holds the domain, `.nojekyll` keeps Jekyll from touching anything, and pushing is the whole deploy.
