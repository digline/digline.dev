# Walkthroughs

Come to see how it is used: five applications, from the first recorded call to
a gate, every step run.

- **[A Quarkus application on Bedrock](java-quarkus-bedrock.md)** — Java on
  Quarkus, calling Bedrock through the AWS SDK for Java.
- **[A Python application with three prompts](python-three-prompts.md)** —
  three prompts, three suites and three verdicts.
- **[A Node application on three SDKs](node.md)** — OpenAI, Anthropic and
  Bedrock from one Node service.
- **[From the IDE's agent, over MCP](from-the-ide-over-mcp.md)** — the agent
  in the IDE reads and measures through `digline-mcp`, and the person decides.
- **[An agent in Python](an-agent.md)** — a loop of model and tools, and a gate
  on its steps.
