# Contatti

Scrivi a [hello@digline.dev](mailto:hello@digline.dev) — domande sull'uso di digline e tutto ciò che non trova posto in una issue pubblica.

Per bug e richieste di funzionalità è meglio aprire una [issue](https://github.com/digline/digline/issues), dove la risposta resta leggibile per chi si imbatte nella stessa cosa.

Le segnalazioni di sicurezza vanno allo stesso indirizzo; per favore non aprire prima una issue pubblica.
