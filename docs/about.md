# About

digline is an open-source tool for keeping LLM applications under control, released under Apache-2.0. It is built and maintained by Alessandro Prandini.

It came out of building an AI product and needing to know, after every change to a prompt or a model, which answers had got worse.

The code, the issues and the releases are on [GitHub](https://github.com/digline/digline).
